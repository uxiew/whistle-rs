# 安全运行与数据边界

[快速开始](../README.md) · [参数](CLI.md) · [证书](CERTIFICATES.md) · [当前已知问题](STATUS.md)

这是开发调试代理，不是已经通过隔离验收的多租户网关。只代理获授权的设备与流量；能修改规则或插件的人通常也能改变代理可访问的目的地和文件，不能把它们当作不受信任的普通配置。

## 本机使用

```sh
./target/release/whistle-rs -H 127.0.0.1 -p 8899 --no-persist -r rules.txt
```

此命令不修改系统代理、不安装信任证书。手动把客户端 HTTP/HTTPS 代理指向 `127.0.0.1:8899`；命令行验证时注意已有 `NO_PROXY`/其他代理变量，`curl --noproxy '' -x ...` 可显式使用本代理。HTTPS 的按命令 CA 信任示例见 README。

需要只转发而不解密 HTTPS 时使用 `--no-intercept-https`。不要把它与 `-M pureProxy` 混同：本项目的 `pureProxy` 用于控制特殊控制台域名的处理，不是这项开关的可靠替代。

## 默认值与共享访问

| 项目 | 当前默认值 / 边界 |
| --- | --- |
| 监听 | `0.0.0.0:8899`；示例显式改成回环，默认本身并不安全隔离 |
| 控制台 | 未配置用户名/密码时开放；`-n/-w` 管理账户、`-N/-W` 只读账户；只保护相应 UI/API，不等于代理转发认证 |
| 独立 UI 端口 | `-P` 可以分端口；不自动增加独立绑定地址或防火墙隔离策略 |
| HTTPS | 默认拦截；源站证书默认校验。`--insecure-upstream` 降低安全性，不作为通用排障建议 |
| 历史 | 默认会话落盘，保留 7 天；`--no-persist` 关闭会话持久化，不阻止 CA/规则配置写入或 `reqWrite/resWrite` 显式写文件 |
| 跨域 | 不要为图方便开放 `--allow-origin '*'`；CORS 不是非浏览器客户端的身份认证 |

手机/局域网调试须显式选择可达地址，并用操作系统防火墙、受控网络或已有安全隧道限制客户端。不要在路由器上将代理端口直接映射到公网。认证参数可能进入进程列表和 shell 历史；不要把真实密码写进仓库、报告或演示命令。当前没有在此文档中承诺代理自带 IP ACL、口令文件或环境变量注入接口。

`multiEnv`/`enableRequestHeaderRules` 允许请求携带规则，应仅在已限定调用者的场景启用。它不是租户隔离机制。代理进程采用最小文件权限，不以管理员身份长期运行，插件及远程规则来源须受信任。

## 采集与保留

Body 预览默认 16 KiB；缓冲响应改写上限默认 16 MiB。两者不是同一设置，也不是整个进程的内存上限。预览、导出和重放涉及有界捕获数据，不能假设每个报文都完整；达到改写上限时部分操作可能回退为原样转发，见 RULES 与 STATUS。

控制台搜索、Include/Exclude 显示筛选与服务端“是否采集”是不同层。**画面没显示不证明内存/API/磁盘没有该请求。** 会话可能含 Authorization、Cookie、个人数据或业务密钥；分享 HAR、JSONL、截图及插件日志前审查内容。

默认存储在 `~/.whistle-rs`，也可用 `--dir` 指定专用目录。CA 公钥证书可以交给获授权的客户端，私钥不能分享。备份、导出、清屏、按天过期和删除历史是不同操作；`--no-persist` 不删除之前留下的文件。删除/迁移目录前先停止对应实例，避免误删其他实例的数据。

## 排障顺序

先确认客户端真的经过本代理，再用 `explain` / Test Rules 查匹配，最后查看请求详情和 `-v` 日志。早期 DNS/连接/TLS 失败可能只有客户端 502 与日志，而没有完整会话；这项缺口计划在 O1 修复。

写延迟用纯数字毫秒，例如 `resDelay://1000`；`1s`、`500ms` 不是有效的延迟数值。证书错误优先核查信任关系、源站证书和目标端口，不用关闭所有校验掩盖问题。停止调试后撤销不再需要的客户端代理设置与 CA 信任。
